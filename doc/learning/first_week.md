# 第一周：用 4–6 小时开始，不采购

本周只解决三个问题：这个工程处理什么数据；程序如何帮助计算；自己是否理解输出。完成后在 [进度表](progress.md) 第 01 周填证据，尚未理解的项目保持未勾选。

## 0. 先建立自己的记录（20 分钟）

在任意自己方便的位置建立 `MCVS-study/week01/`，不要覆盖仓库里的教材。建立 `notes.md` 或纸质笔记，写下日期、用时和这句话的补全：

> 相机给我 ______；IMU 给我 ______；我想知道设备如何运动，所以还需要知道 ______。

可参考答案：图像；加速度和角速度读数；每个数据的坐标系、单位、采样时间及传感器之间的关系。用自己的话表达即可。

## 1. 认识一条数据（40 分钟）

读 [基础手册第 1–3 节](foundations.md)。先用计算器算出：

1. 30 fps 每秒有 30 帧，平均每帧隔 `1 / 30` 秒，即多少毫秒？
2. 1280×720 的单通道 8 位图像，未压缩时有多少字节？
3. 两台这样的相机都以 30 fps 记录，理想原始数据量每秒多少字节？

答案：约 33.333 ms；921600 B；55296000 B/s。每一步写出单位。这里未计压缩、数据头和传输开销，也没有测量真实设备吞吐。

## 2. 运行第一个程序（40–60 分钟）

先在 Windows PowerShell 中检查：

```powershell
py --version
```

若显示 Python 3 的版本，继续；如果 `py` 不存在，再试 `python --version`。若两者都没有可用 Python 3，按照 [Python 官方 Windows 安装说明](https://docs.python.org/zh-cn/3/using/windows.html) 安装。只做基础 Python 安装，不需要 CUDA、ROS 或完整科学计算环境。安装界面可能变化，以官方说明为准。

在项目根目录运行：

```powershell
Set-Location -LiteralPath 'C:\Users\27348\Desktop\MCVS'
py .\doc\learning\examples\first_steps.py
```

如果你的命令是 `python`，把 `py` 替换成 `python`。本例只用 Python 标准库，不需要 `pip install`。后续设备或路径变化时，先切换到实际项目目录。

成功输出中应包含 `frame interval: 33.333 ms`、`projected u: 380.000 px` 和 `stereo depth: 1.200 m`。把输出保存到自己的笔记，不必第一次就读懂所有函数。

### 先认识四种写法

```python
fps = 30                   # 变量：给一个值起名字
interval_ms = 1000 / fps    # 运算：等号右边算完，保存到左边
print(interval_ms)         # 调用函数：显示结果
if fps <= 0:               # 条件：冒号后缩进的内容属于这个分支
    raise ValueError("fps must be positive")
```

Python 的缩进有意义。`=` 是赋值，`==` 是比较；`#` 后是注释；文件扩展名应是 `.py`，不要变成 `.py.txt`。`print` 显示值，不会自动把结果保存成数据文件。

## 3. 预测、修改、解释（60–90 分钟）

先把示例复制到自己的 `week01` 文件夹，再修改副本。每次修改前写预测，运行后记录是否一致：

| 修改 | 预期现象 | 为什么 |
|---|---|---|
| `FPS = 30` 改成 `60` | 帧间隔约 16.667 ms，原始吞吐翻倍 | 每秒帧数翻倍 |
| `POINT_Z_M = 2.0` 改成 `4.0` | 横向像素从 380 变为 350 | 点更远，离主点更近 |
| `DISPARITY_PX = 30.0` 改成 `15.0` | 深度从 1.2 m 变成 2.4 m | 理想平行双目中深度与视差成反比 |

做完后恢复原值。再故意设 `FPS = 0`，观察报错中的 `ValueError` 与行号：报错是输入不满足约束的反馈，不代表电脑坏了。恢复后重新运行。

本周不要求推导投影公式，先看懂“输入改变，输出按规律改变”。公式在第 9、19 周再完整学习。

## 4. 少量课程 + 复盘（60–90 分钟）

打开 [CS50P 的 Functions, Variables](https://cs50.harvard.edu/python/2022/weeks/0/)，先学习其中变量、函数和 `print` 的部分，单次最多 45 分钟；课程为英文，可先读本地中文解释，再核对代码。零基础无需一周看完整课。

Python 中文官方教程是语法参考，它本身假设读者有基本编程概念；不把它当作唯一的入门教学。

闭卷回答：

- 图像、IMU、时间戳分别解决什么问题？
- 为什么 30 fps 不等于 30 ms？
- 输出的 MB/s 是理论未压缩量，还是摄像头实测值？
- 修改一个输入前，能否预测变化方向？
- 报错时应保存哪三样东西？（完整命令、版本、第一条错误及上下文。）

## 卡住时的处理

| 现象 | 先检查 | 本周仍可做的事 |
|---|---|---|
| 找不到 `py` / `python` | 官方安装说明；重新打开终端 | 手算表格，阅读变量示例 |
| 找不到脚本 | 当前目录、文件名、`.py.txt` | 从文件管理器确认路径 |
| `SyntaxError` / `IndentationError` | 中英文标点、冒号、缩进 | 对照原始文件，只改一个值 |
| 输出和教材不同 | 是否改过参数；单位是否一致 | 将原值与改值各记一行 |
| 2 小时仍无法运行 | 保存报错与已做操作 | 完成手算预备任务；运行项保持未通过 |

本周交付：一页笔记、原始输出、三次参数修改的预测与结果。无需买摄像头，也无需读论文。下周再系统学习变量、条件、函数。
